# Number Guessing Game (Python)

A simple console game made in Python. The computer picks a secret number between 1 and 50, and you try to guess it.

## Features
- The computer picks a random number from 1 to 50
- You can guess as many times as you need
- Hints after each guess: "too low" or "too high"
- The game ends when you find the number

## Technologies Used
- Python
- `random` module
- `while` loop and `if / elif / else`

## How to Run
1. Save the code as `guessing_game.py`.
2. Open a terminal in that folder.
3. Run:
   ```
   python guessing_game.py
   ```

## Sample Output
```
Guess a lucky number between 1 to 50 : 25
Too high
Guess a lucky number between 1 to 50 : 12
Too low
Guess a lucky number between 1 to 50 : 18
Congratulations! You found it 18
```
